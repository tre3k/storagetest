# storagetest

A simple program to check the speed and performance of some storage devices.

## intro

Слишком много рынок заполонил поддельными флешками =), эта программа
призвана тестировать флешки/SD карты на фактический объем и скорость
записи/чтения. Таких программ много, например CrystalDiskMark для
Windows, в GNU/Linux также существует множество способов проверки
носителей на ошибки, начиная от kdiskmark (аналог вышеупомянутого
crystaldiskmark) и закачивая более unix-way способом используя
например dd, вкупе например с sha256 и.т.д.

Зачем же тогда она нужна?
* Это может быть одна из первых попыток моего осознанного
  программирования, т.е. не тупо реализация функционала "просто чтобы
  работало", но с задумкой об архитектуре.
* Может быть не очень правильно выбран язык си? Учитывая первый пункт
  мне было бы наверное удобнее использовать с++ или еще чего хуже
  что-то из скриптовых python? ruby? или например мне сейчас нравится
  julia? Но я решил все таки си, о чем следующий пункт.
* Хочется простой консольной утилиты в традициях linux. Также
  необходим потоковой подсчет контрольной суммы с одновременной
  записью/чтением (что требует довольно большой цепочки команд если
  следовать unix-way и не хочется плодить временные большие файлы,
  т.е. делать сразу все в потоке, хотя впрочем ничего не мешает
  написать bash скрипт).
